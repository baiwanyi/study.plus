# 2026-10-12

## 本地题库支持图片
- 后端 `server/src/routes/library.ts`：
  - 扫描范围由「仅 `.md`」扩展为「`.md` + 图片白名单」（`png/jpg/jpeg/gif/webp/bmp`；不含 SVG，避免内嵌脚本面）。
  - 新增 `resolveFileType()` 统一归类（md → `markdown`，白名单图片 → `image` 并带 MIME），`scanMarkdownFiles` 改名 `scanLibraryFiles` 并返回 `{ absPath, type }`，避免二次判类型。
  - 清单与内容接口均新增 `kind` 字段；图片标题取文件名、`fullScore` 恒为 null；`resolveSafePath` 的扩展名校验改为调用 `resolveFileType()`。
  - 图片内容走 `type.kind === 'image'` 分支提前 return，以 `data:<mime>;base64,…` 内联返回（前端 `<img>` 直出，响应体不含服务端绝对路径）；图片上限 4 MB（base64 膨胀约 1.37 倍），Markdown 仍为 1 MB；MIME 只取扩展名白名单，不读文件内容做嗅探。
- 前端：
  - `apps/src/services/library.ts` 新增 `LibraryFileKind`，`LibraryFileMeta`/`LibraryFileDetail` 增加 `kind`，路径校验放行图片白名单扩展名；`services/index.ts` 导出新类型。
  - `pages/Library/index.tsx`：`kind === 'image'` 时不走 `MarkdownView`，直接 `<img src={dataUrl}>` 居中自适应展示；分值/公式预处理只对 Markdown 执行；空态文案改为「暂无题目文件」并提示可放图片。
  - `pages/Library/components/LibrarySidebar.tsx`：图片项以 lucide `Image`（别名 `ImageIcon`）图标替代分值徽标。
- 文档：`README.md` 功能列表、本地题目章节、目录结构注释同步（图片支持、体积上限、安全约束）。
- 测试：新增 `server/__test__/library.e2e.test.ts`（4 用例：清单类型标注 / data URL 与原始字节一致 / Markdown 原文与满分 / 非白名单扩展名与越界路径 403）。
- 验证：`server`、`apps` 两端 `tsc --noEmit` 通过；后端全量 vitest 8 文件 39 用例全通过（含本次新增 4 用例）。
- 遗留：Markdown 正文中引用的相对图片（`![](./img/a.png)`）仍无静态托管，题库内图片需作为独立文件阅读。
