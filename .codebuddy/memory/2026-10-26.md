## 新增功能：每日练字（A4 字帖生成）

### 功能范围

- A4 纵向单页，11 格 × 14 行，三种方格：田字格 / 米字格 / 九宫格
- 内容来源四类：自定义、古诗词（整首）、课文节选（≤20 字）、课外读物节选（≤20 字）
- 字体：本地已安装字体三级枚举（queryLocalFonts → canvas 探测候选表 → 手工输入）
- 输出：浏览器打印 / 另存 PDF，矢量字体与虚线，不落库、不改后端接口

### 实现要点

- 几何常量集中在 shared，页高取 296mm（比 A4 少 1mm）以避免 96dpi 取整多出空白页
- 字帖底纹按整页合并为单个 SVG 绘制，避免逐格渲染时相邻边框错位成双线
- 排版纯函数处理避头（行首闭标点挤入上一行末格）与避尾（行末开标点移到下一行）
- 标点策略默认「标点占格」，可切换「标点随字」（标点压在前字右下角）
- 语料为 Markdown 文件，按 `## 标题` + `> 引用行` 约定解析，用户可直接增删

## 修复：shared 层不得依赖 DOM/Node 全局

### 问题

IDE 报 `handwriting.ts` 中 `console` 找不到（TS2584）。根因：`shared/tsconfig.json` 的 `lib` 仅 `ES2023`，
既无 DOM 也无 Node 类型，因此 `console` 与 `crypto` 都不在该编译单元的全局环境内。

### 修复

- `filterPassageEntries` 改为返回 `{ entries, rejected }`，不再内部 `console.warn`，
  由 `useHandwritingCorpus`（浏览器侧）负责汇总告警
- `pickRandomEntry` 从 `crypto.getRandomValues` 改为 `Math.random`（抽诗场景无需密码学随机）
- 单测同步断言 `rejected` 分组

### 约定

shared 是浏览器与 Node 共用层，编写时只用 ECMAScript 标准对象，不碰 `console`/`crypto`/`window`/`process`；
需要环境能力时以参数或返回值传递给调用方。

## 修复：预览区出现水平滚动条

### 根因

字帖高度超出视口 → 出现竖直滚动条 → 可用宽度减少约 15px，而预览宽度仍是上一帧按旧容器宽算出的定值，
多出的部分撑开了默认 `overflow: visible` 的 `flex-1` 容器，于是出现水平滚动条。

### 修复

- 预览容器补 `overflow-hidden`，多出的宽度不再撑开外层
- `.hw-sheet-viewport` 补 `max-width: 100%` 兜底，滚动条出现的瞬间也不会反向撑宽页面
- ResizeObserver 会在宽度变化后重新计算缩放比，稳定态下不再裁切

### 涉及文件

- `apps/src/pages/Handwriting/index.tsx`
- `apps/src/styles/handwriting.css`

## 需求调整（同日，第六轮）：任意屏宽自适应

### 调整内容

改用纯 CSS 等比缩放，彻底去掉 JS 测量与 transform：

- `.hw-sheet-viewport` 设 `container-type: inline-size` + `width: 100%`，作为容器查询基准
- 字帖内所有尺寸（纸张高、页边距、格边、行距、字号）改用 `cqw` 表达，
  由 `toCqw(mm) = mm / 210 * 100` 换算，字帖宽固定 100cqw
- 删除 `previewScale` / `previewRef` / `ResizeObserver` / `MM_TO_PX` 及 `.hw-sheet-scaler` 层级
- 打印时 viewport 宽仍等于页面宽（210mm），`100cqw` 自动还原为真实毫米，1:1 输出不变

### 为什么优于 JS 测量

JS 方案需要处理"竖直滚动条出现 → 容器变窄 → 比例过期 → 撑出横向滚动条"的循环，
且首帧必然错一帧；容器查询单位由浏览器布局直接求解，不存在测量时序问题。

### 前提

容器查询单位需要 Chrome 105+ / Safari 16+ / Firefox 110+，与项目 Vite 8 + React 19 的目标环境一致。

## 需求调整（同日，第八轮）：居中改为左多右少

### 改动

`centerCells` 前导空格由 `Math.floor` 改为 `Math.ceil`：留白为奇数时左侧多一格、右侧少一格；
整除时两侧相等、不变。例：6 字句留白 5 格 → 左 3 右 2。

### 影响范围

标题、作者行与诗句共用同一居中函数，因此三者的奇数留白一律左偏一格
（如 8 字的「〔唐代〕杜甫」由左 1 右 2 变为左 2 右 1）。

### 补充：字体列表可得性

局域网 http 地址（如 `http://192.168.x.x:5173`）不算安全上下文，`navigator.queryLocalFonts`
不存在，面板原本连「读取全部本地字体」按钮都不渲染，只能看候选表。处理：

- 候选表按用途分组扩到 43 项（楷书 / 隶书 / 行楷手写 / 仿宋宋体 / 黑体圆体 / 开源），
  覆盖 Windows 预装与 Office 附带的华文、方正系列，以及 macOS 预装中文字体
- `useLocalFonts` 增加 `isInsecureContext`，面板据此给出可操作提示（改用 localhost 或 https）
- 完整列表仍只能由 `queryLocalFonts` 授权后获得：Chrome 可把该源加入
  `chrome://flags/#unsafely-treat-insecure-origin-as-secure` 临时解锁

### 补充：候选表外的字体改走内置字体分发

用户手装的第三方字体（如「方正手迹-旅行青蛙体 简」，用户级安装于 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`）
既不在候选表、非安全上下文又读不到 API，下拉里必然缺席。最终方案不是手填，而是**把字体随站点分发**：

- 字体文件放 `apps/public/fonts`，`apps/plugins/handwriting-fonts.ts` 扫描目录生成 `virtual:handwriting-fonts`
  清单（族名经 `normalizeFontFamilyFromFile` 规范化，label 取文件名），dev 下增删文件触发整页刷新
- `useLocalFonts.ensureFont` 用 `FontFace` 按需加载，选中哪款才下载哪款
- 下拉分「内置字体 / 系统字体」两个 optgroup，同族名去重且内置在前；手填入口已移除，只能从清单选

## 修正（同日，第三十一轮）：子标题顶格与题号按钮顶对齐

### 问题与处理

- 子标题（`**（二）先做后合作**`）不顶格：加粗分组标题不是 Markdown 标题，解析器把它并入上一题块，
  于是跟着题干列一起缩进。处理：`parseLibraryQuestions` 识别「独占一行的加粗中文序号标题」
  （`LIBRARY_GROUP_HEADING`），flush 当前块并独立成 text 块，同时用去加粗后的文本更新 section
- 题号块/按钮与题干首行未顶对齐：题干列原有 `pt-1`（4px）叠加 27px 行高（15px × 1.8）导致文字下沉。
  处理：去掉 `pt-1`，题号块与按钮改为 `h-7`（28px，与行高齐平），两块改用 `border-l-0` 共边
- 注意：加粗分组标题独立成块会改变后续题块的 index，若旧文件已保存 `<!-- hint:N -->`，
  思路归属可能整体后移一位（现有含 hints 的文件不含分组标题，暂未受影响）

## 新功能（同日，第三十轮）：文件列表悬停删除

### 功能范围

- 题目清单条目悬停时右侧浮出删除按钮（Trash2）：`group` + `group-hover:opacity-100`，
  条目右侧留 `pr-9`、原分值/图片徽标在悬停时淡出让位，点击不会误触条目本身
- 点击后弹「确认删除」（`Modal` + `danger`，展示标题与相对路径，提示不可撤销），
  确认后删除并刷新清单；删的是当前题目时先切到剩余第一份再 reload，避免详情请求命中已删文件
- 小屏抽屉里点删除会先收起抽屉，再开确认弹窗

### 接口与实现

- 新增 `DELETE /api/library/file?path=`：复用 `resolveSafePath`（越界/非白名单 → 403）、
  缺参数 400、文件不存在 404；只允许删除普通文件（不删目录），软链在扫描阶段已跳过
- 删除走 `enqueueFileWrite` 同一文件队列，避免与思路写回的读-改-写并发
- 不提供回收站，删除即不可恢复（弹窗已明确告知）

### 验证结果

- `tsc --noEmit`（apps / server）：均无错误；lint 无告警
- `pnpm test`：10 个测试文件、82 项全部通过；`library.e2e.test.ts` 4 → 6 项，新增：
  - 删除文档后文件消失且不再出现在清单中：通过
  - 删除不存在的文件返回 404，越界/非白名单返回 403，缺参数返回 400：通过
