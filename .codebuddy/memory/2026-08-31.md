# 2026-08-31

## 调整：任务分享导出图片文件名格式

- 需求：分享下载文件名由 `分享_{Title}.png` 改为 `分享_{Date}_{Title}.png`。
- 最终口径：`{Date}` 取**作业提交日期** `task.submittedAt` 的 `YYYY-MM-DD`（用户确认，非导出当天日期）。
- 实现：模块级纯函数 `formatSubmitDate(iso)` 转日期段，缺失或非法日期一律回落「未提交」（避免 `Invalid Date` 进文件名）；标题仍清洗 Windows 非法文件名字符 `/ \ : * ? " < > |` 为 `_`；`useCallback` 依赖同步加入 `task?.submittedAt`。
- 未复用 `shared` 的 `formatDate`：其输出含中文与冒号、空格，不适合做文件名。
- 涉及文件：`apps/src/pages/Tasks/TaskModalShare.tsx`。
