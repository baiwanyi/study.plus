## 环境修复：后端启动报 Cannot find module 'serve-static'
- 现象：`pnpm dev:all` 的后端进程崩溃，`express` 加载时 `Cannot find module 'serve-static'`。
- 根因：依赖树不一致 —— `.pnpm\express@5.2.1_supports-color@10.2.2\node_modules\serve-static` 链接指向 `.pnpm\serve-static@2.2.1_supports-color@10.2.2`，但该目录磁盘上不存在（只有不带后缀的 `serve-static@2.2.1`），应为先前局部 `pnpm --filter apps remove/add` 增删依赖后留下的残留状态。
- 处理：仓库根执行 `pnpm install`（输出 `Packages: +3 -1`，lockfile 未变）重建链接；`serve-static@2.2.1_supports-color@10.2.2` 恢复存在。
- 验证：后台启动 `pnpm --filter server start`，日志出现 `Server listening on port 3001`，冒烟通过后已停止该进程。
- 涉及文件：无代码变更（仅 `node_modules` 依赖链接）。
