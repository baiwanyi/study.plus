常见问题

你可能想先弄清楚的几件事

我的数据存在哪里，会不会上传到别人的服务器？

全部数据存在你本地机器的 SQLite 数据库里，除你主动调用的 DeepSeek API 外，不依赖任何第三方云服务。数据库每日备份也会发往你自己的邮箱。

部署门槛高吗？需要哪些准备？

只需要 Node.js ≥ 20.11 和 pnpm。deploy 目录完全自包含，拷贝到服务器即可运行，无需再安装 node_modules；Windows Server 上可用 nssm 注册为系统服务。

没有 DeepSeek API Key 也能用吗？

可以。作业评分、积分账本、周报、电台、RSS 等核心能力不依赖 AI Key；AI 评语与费曼评估等增强功能需要配置 DeepSeek API Key 后才会启用。

积分规则可以自己改吗？

可以。A+~E 各档分值、月初始积分、特权最低积分、兑换比例、预支分期规则都在规则页在线编辑，改完即时生效，不需要重启服务。

本地部署版还会继续更新吗？

本地版已停止功能开发，仅做 Bug 修复；全新功能开发集中于 CloudBase 版本。你可以持续使用本地版，也可以跟进 CloudBase 分支的演进。

支持哪些作业类型？

日常作业按 A+~E 六档评分；读书笔记有专属评分维度（摘抄赏析 50 分、读后感 40 分、好词好句 10 分）；另支持课堂问答题生成与解锁规则。
